# Dream Garage

## About

Dream Garage is a web application that allows users to search for cars they are interested in and create their own personal collection of dream vehicles. Users can explore different makes and models, view car information and images, and save their favorite cars into a personalized garage.

The goal of this project was to create an interactive and visually engaging experience centered around car enthusiasts who want a place to keep track of vehicles they admire or hope to own in the future.

## Features

- Search for cars by make and model
- View vehicle details and images through APIs
- Save cars to a personal garage
- Remove cars from the garage
- Persistent saved cars using local storage
- Responsive design for desktop, tablet, and mobile
- Animated and interactive UI elements

## Technologies Used

- React
- Vite
- Tailwind CSS
- Framer Motion
- Git & GitHub
- Local Storage
- Car APIs

## My First React Project

Dream Garage was my first project built using React, and it represented a major transition from creating websites with only HTML, CSS, and JavaScript.

Previously, I focused on building static websites where each element was manually structured and updated. With React, I learned how to create reusable components, manage state, pass data between components, and build a more dynamic user experience.

This project challenged me to think differently about web development by focusing on how data flows through an application rather than just how a page looks.

## API Integration

A major focus of this project was learning how to work with APIs. Instead of relying on hardcoded information, Dream Garage retrieves vehicle data dynamically and uses external services to provide car details and images.

Through this process, I learned how to:
- Make API requests
- Handle asynchronous data
- Work with JSON responses
- Display dynamic information based on user input
- Connect external services into a React application

One of the biggest takeaways from this project was moving beyond traditional HTML and CSS development.
